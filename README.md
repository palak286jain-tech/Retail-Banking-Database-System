# Retail Banking Database System

## Project Overview
A Retail Banking Database System developed for the BCSE302L Database Systems course.

The project uses Oracle SQL, PL/SQL, and Python to manage banking operations and generate reports.

## Technologies Used
- Oracle Database XE
- SQL and PL/SQL
- Python
- Tkinter GUI
- python-oracledb

## Project Files
- `bank_app.py` – Python command-line banking application
- `bank_gui.py` – Desktop graphical user interface
- `Banking_Review2.sql` – Database schema and implementation
- `Banking_Review3.sql` – Additional database procedures, functions, triggers, and reports
- `Retail_Banking_Database_System_Report.docx` – Project documentation

## Setup
1. Install Python and configure Oracle Database.
2. Install the Python database driver: `pip install oracledb`
3. Run `Banking_Review2.sql` in the intended Oracle schema.
4. Run `Banking_Review3.sql` in the same schema.
5. Configure the Oracle connection in the Python application.
6. Run `python bank_app.py` or `python bank_gui.py`, depending on the interface you want to use.

## Note
This project is an academic database systems project. The applications require a configured Oracle database to operate.
